# LF-005 Synthetic dataset

Generated by `tools/generate_synthetic_leads.py`. Do not edit by hand: change the generator and rerun it.

## What it is

100 fictional inbound enquiry events for MoP Cloud between Monday 12 October and Friday 6 November 2026 (Europe/Madrid), with follow-up activities and the expected outcome of every event under `LF-RULES-v1.0`. All names use invented people and companies; every domain ends in `.example`.

## Files

| File | Content |

| `data/synthetic/expected_outcomes.json` | Expected outcome per event (with LF-004 pattern references and an explanation), lead-level SLA outcomes at the cut-off, summary counts |
| `docs/synthetic_dataset.md` | This page |

## How to regenerate and check

```bash
python3 tools/generate_synthetic_leads.py          # rewrite the files
python3 tools/generate_synthetic_leads.py --check  # fail if they are out of date
python3 -m pytest                                  # validation tests
```

The random seed is fixed (`20261023`), so the files are identical on every run.

## How expected outcomes are produced

- **Outcome first.** Each new lead comes from a recipe that states its intended result (for example high fit + low engagement -> P2, rule 5); the inputs are built to match.
- **Checked.** A small reference calculation inside the generator confirms every recipe and works out returning contacts. It shares no code with the routing engine (LF-006/LF-007).
- **Traceable.** Every event lists the reviewed LF-004 scenario(s) it follows.
- **Primary reference.** The hand-reviewed LF-004 scenarios remain the acceptance tests; this dataset adds volume.

## Settings

- Starting rotation: ES-01, PT-01, FR-01 (representative-ID order).
- Unavailability: PT-01 and PT-02 on 21 Oct (offsite), ES-01 on 28 Oct (day off), FR-02 from 2 Nov (left the team).
- Supplier redirect rules exist for ES and FR only.
- SLA and response-target outcomes are evaluated at Fri 06 Nov 18:00 (the cut-off).
- Inactive representatives keep their existing leads but log no activity while inactive.

## Limitations

- Expected outcomes come from the generator's own reference calculation, checked against the recipes. A stratified random sample of 20 was checked by hand: 20 of 20 agreed (`docs/synthetic_dataset_review.md`).
- Public holidays are not modelled (as in the MVP).
- Data is synthetic. No real people, companies or personal data are used.
